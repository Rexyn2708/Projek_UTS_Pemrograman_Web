Vesta — Free Bootstrap 5 Fashion Store Template

Vesta is a premium, distinctively designed clothing-store template for modern
fashion e-commerce. It includes a full storefront (index.html) and a complete
product detail page (product.html) with instant category filtering, a slide-in
cart drawer, a swappable product gallery, colour and size pickers, tabs and a
lightbox — all powered by clean vanilla JavaScript. It is built on Bootstrap 5
(self-hosted, no CDN), uses no jQuery, and is responsive and accessible out of
the box. Vesta is free for both personal and commercial use.
